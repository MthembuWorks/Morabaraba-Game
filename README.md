# Morabaraba-Game
Developed as a joint project with a team partner at Wits University.
List of files and purpose of each file:

main.cpp - only this file needs to be compiled, it includes all other files

GameTypes.h - this file contains two structs (PlayerMove and CellState) which are used for transferring information between different modules

Morabaraba.h - this file contains the Morabaraba class which stores the board and handles all processing of the game

Alg_1.h - this file contains the Alg_1 class which uses a random algorithm

Alg_2.h - this file contains the Alg_2 class which uses a greedy algorithm
